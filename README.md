# Memory Game

## Игра на память и внимательность!

### Правила игры:

- На поле 16 карточек: 8 разных изображений, каждое встречается дважды. Во всех играх можно использовать один набор изображений.
- Игрок нажимает на закрытую карточку, затем на другую.
- Если изображения совпали, обе карточки остаются открытыми до конца игры. Можно выбирать следующую пару.
- Если изображения различаются, обе карточки закрываются.
- Когда найдены все 8 пар, игра завершается - вы выиграли!

### Как запустить локально:

#### Способ 1:

- Скачать [архив](https://github.com/Al-E-xXx/memory-game/archive/refs/heads/memory-game.zip) к себе на компьютер.
- Распаковать
- Открыть `index.html` в браузере.  
  _Внимание! При таком способе запуска могут быть проблемы с Local Storage_

#### Способ 2:

- Клонировать себе [репозиторий](https://github.com/Al-E-xXx/memory-game)
- Открыть в VS Code
- Перейти в ветку `memory-game`
- Открыть файл `index.html`
- Запустить локальный сервер (Live Preview)  
  _Должен быть установлен плагин `Live Preview`_

_По всем вопросам обращайтесь в Дискорд автора, и возможно, он когда-нибудь ответит_
